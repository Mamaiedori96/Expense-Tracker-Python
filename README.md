# 💰 Personal Expense Tracker

A terminal-based expense tracker built with Python.

## Features

- Add income
- Add expenses
- Expense categories
- View all transactions
- Calculate current balance
- View total income and expenses
- View spending by category
- Save transactions using JSON
- Input validation
- Handles missing or invalid JSON files

## Categories

- Food
- Transport
- Games
- Clothes
- Other

## Technologies

- Python
- JSON

## How to Run

```bash
py main.py
